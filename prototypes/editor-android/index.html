    Why it differs from the web build

    Panels become surfaces

    Three panels cannot fit beside a 375 dp canvas on a 412 dp screen. At rest nothing is open; selecting a node summons a peek sheet, and a chip expands it to half height.

    The nudge pad replaces arrow keys

    A finger lands within ~20 dp of intent. Drag gets you close, the pad gets you exact — 1dp per tap. There is no keyboard to hold an arrow key on, so this is UI, not a shortcut.

    Targets are 48 dp, visuals are not

    Resize handles draw at 14 px but carry a 48 dp transparent target. Same trick Material uses for icon buttons — the visual stays small, the hit area does not.

    Tools sit at the bottom

    On a 915 dp screen the top bar is out of thumb reach one-handed. The rail lives where the thumb already rests; the app bar keeps only what you press rarely.
